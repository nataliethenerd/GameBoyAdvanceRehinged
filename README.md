# Game Boy Advance Rehinged (WIP)

Did you know that the Game Boy Advance (AGB) and the Game Boy Advance SP (AGS) are basically the same, with a different pinout? Yet the SP is more expensive on the second hand market.

This board uses the CPU from the GBA (the wide one) and rehinges it
